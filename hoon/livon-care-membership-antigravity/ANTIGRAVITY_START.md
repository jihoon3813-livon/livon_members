# 안티그래비티 작업 시작 안내

이 폴더는 리본케어 멤버십 홈페이지의 개발용 소스입니다. 먼저 README.md와 HANDOFF.md를 읽고, 패키지 설치 및 실행 후 기존 화면을 확인해 주세요.

## 작업 목표

현재 디자인과 상품 문구를 유지하면서 사용자가 요청한 부분을 수정합니다. 기존 페이지를 새 템플릿으로 재구성하거나 상품 조건을 임의로 바꾸지 않습니다.

## 먼저 실행할 작업

```bash
npm ci
npm run dev
```

수정 후에는 다음 명령으로 검증합니다.

```bash
npm run build
```

## 유지할 기준

- 브랜드: 밝은 세이지·아이보리·딥그린, 버튼 등 필요한 곳의 핑크 포인트.
- 최신 서비스 기간: 가입 후 2년 경과 시점부터 6년간. 최초 2년 동안은 서비스 제공 전 기간.
- 상품: LITE 최장 7일 / SPECIAL 최장 15일 / PREMIUM 최장 30일 간병 지원.
- 가격 정보는 화면·메타데이터·다운로드 내용에 넣지 않음.
- 건강관리 3종은 동일한 제휴 예정 구성. 제휴 완료 또는 적용 조건이 확정된 것으로 임의 변경하지 않음.
- 혜택을 먼저 보여주되 사전 지정·총 1회·잔여일 소멸·초과분 부담은 현재처럼 확인 가능한 안내에 유지.
- 실제 이용 후기, 고객 수, 매칭률, 보험사 제휴 실적 등을 만들어 넣지 않음.
- 실제 상담 채널 연결 전까지 현재 버튼은 상담 준비 기능으로 유지. 전송하지 않은 데이터를 접수 완료로 표시하지 않음.

## 수정 위치

`src/App.tsx`의 `plans`, `healthServices`, `faqs`가 핵심 데이터입니다. 화면 스타일은 `src/styles.css`, 이미지와 폰트는 `public/`에 있습니다.

서비스 기간은 상품 비교 아래, 하단 이용 안내, 상담 창, 복사·저장 문자열에 함께 들어 있습니다. 기준 변경을 요청받으면 관련 문구가 모두 일치하는지 확인하세요.

## 확인 기준

- PC와 390px·360px 모바일 폭에서 글자나 카드가 겹치지 않을 것
- 모바일 메뉴, 내부 이동 링크, FAQ, 상담 준비 창이 동작할 것
- 상품을 선택하면 상담 창의 관심 상품이 맞게 표시될 것
- 복사·TXT 저장에 최신 상품 조건이 반영될 것
- 가격이나 이전 서비스 기간 안내가 다시 들어가지 않을 것
- `npm run build`가 통과할 것

먼저 현재 사이트를 실행한 뒤 사용자의 구체적인 수정 요청을 적용하세요.
