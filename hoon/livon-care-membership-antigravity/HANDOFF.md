## 상담 접수 연결 시 필요한 결정

현재 상담 준비 기능은 브라우저 내 선택·복사·파일 저장만 수행한다. 서버로 신청 내용을 전송하지 않는다.

실제 접수로 바꾸려면 수신 채널(카카오톡, 이메일, CRM 등), 수집 항목, 개인정보 안내·동의, 실제 접수 성공·실패 처리, 운영 담당자의 확인 경로를 정한 후 구현한다. 계정 정보나 인증 키는 소스에 직접 쓰지 않는다.

## 검증 범위

원본 사이트의 PC·모바일 화면과 기능은 이전 제작 단계에서 확인했다. 이 개발용 패키지는 동일한 화면 코드를 Vite로 옮겼으며, 2026년 11월 9일 별도의 의존성 설치, TypeScript 검사, 프로덕션 빌드가 모두 통과했다. 원본 화면 코드·CSS·이미지와 내보낸 파일의 일치도 확인했다. 자동 가입·결제·상담 발송 기능은 없다.
