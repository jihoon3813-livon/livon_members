# 리본케어 간병플러스 · Antigravity 개발 안내

제휴 고객에게 간병플러스 10·20·30의 간병인 지원과 공통 헬스케어를 소개하는 한국어 반응형 랜딩입니다. 2026년 11월 19일 개편본(v2, `55975722`)을 기준으로 구성했습니다.

## 시작하기

1. ZIP을 풀고 Antigravity의 폴더 열기에서 `index.html`이 들어 있는 `livon-careplus` 폴더를 선택합니다.
2. 초안은 `index.html`을 브라우저로 열어 확인할 수 있습니다. 개발 중에는 아래의 로컬 미리보기를 사용하면 브라우저의 로컬 파일 제한 없이 웹폰트까지 확인할 수 있습니다.
3. 소스를 수정하고 미리보기 창을 새로고침합니다. 별도 패키지 설치나 빌드 과정은 없습니다.

### 로컬 미리보기

프로젝트 폴더에서 터미널을 열고 설치된 Python 3에 맞춰 한 줄을 실행합니다.

**Windows**

```powershell
py -m http.server 8000 --bind 127.0.0.1
```

**macOS 또는 Linux**

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 [로컬 미리보기](http://127.0.0.1:8000/)를 엽니다. 종료하려면 터미널에서 Ctrl+C를 누릅니다.

## 어디를 수정하나요?

| 파일 | 내용 |
| --- | --- |
| `index.html` | 상품별 간병 일수, 공통 헬스케어 12개 항목, 제공 주체, 제휴 이용 사례, FAQ 7개와 관련 링크 |
| `styles.css` | PC·모바일 배치, 브랜드 색상, 서체, 모바일 줄바꿈 |
| `app.js` | 스크롤 위치에 맞춘 헬스케어 바로가기 메뉴의 현재 항목 표시 |
| `assets/` | LivOn 로고, 본문 이미지 5장, 한글 웹폰트 3개와 폰트 라이선스 |

상품 카드와 본문은 HTML에서 직접 수정합니다. 메뉴 링크와 해당 섹션의 `id`를 함께 관리하면 바로가기가 유지됩니다. FAQ는 HTML의 `details`와 `summary` 요소로 열고 닫습니다. 웹폰트를 재배포할 때는 `assets/font-license.txt`를 함께 유지합니다.

## 혜택 문구 편집 기준

- 상품명은 ‘리본케어 간병플러스 10’, ‘리본케어 간병플러스 20’, ‘리본케어 간병플러스 30’입니다. 숫자는 최대 간병 지원 일수를 뜻합니다. 세 상품 모두 평상시 건강관리·가족건강관리·주요질병 치료지원 안내를 공유합니다.
- 제휴 고객용 혜택 안내에 맞춰 상품 가격을 표시하지 않습니다.
- 헬스케어 제공 주체는 ‘교보다솜케어 제휴 예정’으로 표기되어 있습니다. 확정 안내를 받은 뒤에 해당 표현을 갱신합니다.
- 대기 2년, 이후 6년의 이용 기간과 지정 대상자 1회 이용 등은 ‘효원 트리플케어 프리미엄’의 사례로 안내합니다. 제휴처 전용판으로 바꿀 때는 해당 계약에서 확인된 조건을 적용합니다.

## Antigravity에서 시작할 때 사용할 요청문

> 이 폴더의 리본케어 간병플러스 랜딩을 로컬 미리보기로 열어줘. 모바일에서 상품 3종과 헬스케어 3개 영역이 잘 읽히는지 보고, 상품별 혜택 보기 버튼과 헬스케어 바로가기, FAQ 열고 닫기를 점검해줘. 이후 요청하는 수정은 기존 HTML·CSS·JavaScript 구조에서 진행해줘.
