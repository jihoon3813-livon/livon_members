# Antigravity 작업 안내

이 프로젝트의 기존 디자인과 상품 조건을 유지하면서 홈페이지를 이어서 개발해 주세요.

1. README.md를 읽고 정적 서버로 실행합니다.
2. 기존 색상(민트·크림·은은한 핑크), 타이포그래피, 모바일 대응을 유지합니다.
3. 전체 서비스 요약은 #service-overview에 있습니다. 상세 항목 버튼은 app.js의 details 데이터와 연결됩니다.
4. 가격·서비스 한도·차감 기준은 임의로 변경하지 않습니다. 확정 전 조건은 확정 혜택처럼 표현하지 않습니다.
5. design-reference 이미지는 선택적으로 사용할 수 있습니다. 텍스트가 포함된 가로 이미지이므로 모바일에서는 작은 글씨가 읽히는지 확인합니다. 현재는 참고 자산이며 적용 여부는 별도 결정합니다.
6. 상담 폼을 실제 운영할 때는 수집 동의, 서버 저장·전송, 접근권한, 오류·성공 응답을 구현한 후 화면 체험 문구를 변경합니다.
7. 변경 후 PC·모바일에서 메뉴, 상세 팝업, 탭, 계산기의 한도 초과 방지, 상담 폼을 확인합니다.
