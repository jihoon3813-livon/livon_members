# 리본케어 홈페이지 — Antigravity 인계본

2026-10-28 최신 수정본. 전체 서비스 요약 섹션(4개 영역, 18개 항목) 포함.

## 실행
이 폴더를 Antigravity에서 프로젝트로 열고 아래 명령을 실행하세요.

```bash
python -m http.server 8080 --directory dist
```
브라우저에서 http://localhost:8080 접속. Python이 없다면 IDE의 정적 웹 서버를 사용하세요.
별도 패키지 설치나 빌드가 필요 없는 HTML/CSS/JavaScript 사이트입니다.

## 파일
- dist/index.html: 페이지 구조 및 전체 서비스 요약
- dist/style.css: PC·모바일 반응형 디자인
- dist/app.js: 케어 탭, 상세 안내 팝업, 케어 조합 계산기, 상담 폼
- design-reference/: 제작한 케어 인포그래픽 참고 이미지. 현재 홈페이지에는 아직 삽입하지 않았습니다.
- ANTIGRAVITY_HANDOFF.md: 작업 요청용 안내

## 현재 상태
- 상품: 160만원 / 통합 7회, 320만원 / 통합 15회
- 치료지원과 스마트 홈케어는 동일한 통합 한도를 공유합니다.
- 간병 24시간 1회, 가사 4시간 0.5회, 정리수납 1곳 4시간 1회, 스마트 홈케어 패키지 5회 차감.
- 간호사 동행과 차량 에스코트의 상세 조건은 확정 전입니다.
- 건강기능식품의 제품·수량과 100만원 상당 제공 목표는 확정되지 않았습니다.
- 상담 폼은 화면 체험용이며 실제 접수·저장·전송하지 않습니다. 운영 전 백엔드 연결과 개인정보 안내 확정이 필요합니다.
- 장비 그림과 인포그래픽은 이해를 돕는 콘셉트 이미지입니다.
