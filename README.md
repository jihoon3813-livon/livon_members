# 리본케어(Livon Care) 라이프케어 멤버십 웹사이트

리본케어 공식 소개 및 상담 신청 반응형 웹사이트입니다.

## 🚀 빠른 시작 (개발 & 프리뷰 서버)

이 프로젝트는 별도 패키지 설치 없이 Node.js 내장 환경으로 즉시 구동됩니다.

```bash
# 서버 시작 (기본 포트 8080 또는 8081)
npm start
# 또는
node server.js
```

브라우저에서 `http://localhost:8081` (또는 콘솔에 안내된 포트)로 접속하세요.

## ✨ 구현 및 고도화 핵심 기능

1. **전체 서비스 요약 (#service-overview)**
   * 4개 영역(평상시, 치료지원, 스마트홈, 추가지원) 및 18개 세부 서비스 항목 구성
   * 각 서비스 항목 클릭 시 이용 기준 상세 모달 팝업 연동
2. **인포그래픽 라이트박스 뷰어 (신규 반영)**
   * `design-reference`의 고화질 인포그래픽 4종을 사이트 각 영역에 배치
   * 원클릭 팝업 라이트박스로 PC·모바일 모두에서 선명하게 확대 및 스크롤 열람 가능
3. **인터랙티브 케어 조합 계산기 (#builder)**
   * 160(7회) / 320(15회) 상품별 실시간 차감 한도 계산 (간병 1회, 가사 0.5회, 스마트홈 5회)
   * 한도 초과 방지 Stepper & 스위치
   * 구성 완료 후 클릭 시 상담 폼에 상품 및 선택 조합 자동 연동
4. **실제 상담 접수 백엔드 연동 (#consult)**
   * 이름 실시간 검증 및 휴대전화 자동 하이픈 포맷팅 (`010-XXXX-XXXX`)
   * 개인정보 수집 및 이용 동의 전문 모달 확인 기능
   * `POST /api/consult`를 통한 실시간 접수 및 접수번호 부여 (`C-XXXXX`)
   * 정적 호스팅 환경에서도 상담 내역이 유실되지 않도록 `localStorage` 백업 저장 기능 내장
5. **완전한 모바일 반응형 UX**
   * 모바일 전용 햄버거 메뉴 및 하단 플로팅 퀵 액션 바
   * 접근성(A11y), 키보드 탐색, Dialog 모달 백드롭 닫기 대응
